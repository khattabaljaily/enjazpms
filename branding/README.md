# Branding

هذا المجلد هو المكان الوحيد الذي تحتاج تعديله لعمل نسخة بمشروع/علامة جديدة
من هذا القالب — بدون لمس أي كود أو قالب HTML.

- `brand.txt` — سطر واحد فقط: اسم المشروع كما يظهر في العنوان، القائمة
  الجانبية، الشريط العلوي، التذييل، صفحات about/pricing، والإيميلات.
- `logo/logo-dark.png`, `logo/logo-light.png` — نفس الأبعاد والشفافية
  الحاليتين لأفضل نتيجة (تُستخدم على خلفيات فاتحة/داكنة بالترتيب).
- `favicon/favicon.png` — ملف واحد فقط، يُستخدم لأيقونة المتصفح ولتطبيق
  الويب التقدمي (PWA) معاً — المتصفح يصغّره تلقائياً حسب مكان الاستخدام.
  يُفضَّل صورة مربعة عالية الدقة (512×512 بكسل فأكثر) لأفضل نتيجة عند
  التصغير. حافظ على نفس اسم الملف بالضبط عند الاستبدال.

بعد استبدال محتوى هذا المجلد لمشروع جديد:
1. `python manage.py collectstatic --noinput` — **ضروري**، وليس اختيارياً:
   النظام يستخدم `CompressedManifestStaticFilesStorage` (whitenoise)، فأي
   ملف شعار/أيقونة جديد لازم يُسجَّل في الـ manifest أولاً وإلا فشلت روابط
   `{% static %}` التي تشير إليه. هذه الخطوة موجودة أصلاً في `deploy.cnf`.
2. أعد تشغيل الخدمة (`sudo systemctl restart enjazpms` أو ما يعادلها) ليتم
   تحميل `brand.txt` الجديد — القراءة تُخزَّن في الذاكرة طوال عمر العملية.
