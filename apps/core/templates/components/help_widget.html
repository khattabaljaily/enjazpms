نصائح سريعة
{% if user|has_perm_key:'view_sales' %}
  1. اختر المبيعات ← فواتير المبيعات
  2. اضغط فاتورة جديدة
  3. اختر العميل وأضف الأصناف
  4. اضغط حفظ ثم تأكيد لإتمام الفاتورة
{% endif %} {% if user|has_perm_key:'view_stocks' %}
  1. اذهب إلى المخزن ← كميات الأصناف لعرض الأرصدة
  2. استخدم الأرصدة الافتتاحية لإدخال أو تصحيح الكميات عند بدء العمل بالنظام
  3. استخدم جرد المخزن لتصحيح الكميات دورياً
  4. أنشئ طلب تحويل لنقل المخزون بين المستودعات
{% endif %} {% if current_tenant.version_type == 'multi_branch' and user|has_perm_key:'view_branches' %}
  1. أنشئ الفرع من الفروع ← فرع جديد، وحدد اسمه وعنوانه
  2. أنشئ مخزن الفرع من المخازن واربطه بالفرع
  3. عيّن مدير الفرع وأضف مستخدمي الفرع من المستخدمين، واربط كل مستخدم بفرعه
  4. خزينة الفرع تُنشأ تلقائياً مع الفرع — لا حاجة لإنشائها يدوياً
  5. قارن أداء الفروع عبر فلتر الفرع في أي تقرير
{% endif %} {% if user|has_perm_key:'view_purchases' %}
  1. اذهب إلى المشتريات ← أوامر الشراء
  2. اضغط أمر شراء جديد واختر المورد
  3. أضف الأصناف والكميات والأسعار
  4. بعد الاستلام اضغط تأكيد لتحديث المخزون تلقائياً
{% endif %} {% if user|has_perm_key:'view_sales_summary_report' or user|has_perm_key:'view_stocks_summary_report' or user|has_perm_key:'view_purchases_summary_report' %}
  • كل التقارير مجمّعة في قائمة التقارير بالشريط الجانبي، مقسّمة حسب الفئة (مبيعات، مشتريات، مخزن، حسابات)
  • في نسخة الفروع المتعددة، فلتر الفرع أعلى كل تقرير يتيح عرض فرع واحد أو كل الفروع مجمّعة
  • كل التقارير قابلة للتصدير إلى Excel/CSV
{% endif %} {% if user|has_perm_key:'view_users' or user|has_perm_key:'view_permissiongroups' %}
  • أضف مستخدمين من الإعدادات ← المستخدمين
  • أنشئ مجموعات صلاحيات لتحديد وصول كل دور
  • راجع سجل النشاط لمتابعة ما يفعله كل مستخدم
{% endif %} {% if user|has_perm_key:'view_employees' %}
  • أضف بيانات كل موظف من الموظفون مع الراتب الأساسي
  • اربط كل موظف بفرعه إن كانت النسخة متعددة الفروع
{% endif %} {% if user|has_perm_key:'view_employee_salaries' %}
  • كشف الراتب: اختر موظفاً، حدد الفترة، أضف بنود الراتب، ثم ادفع
  • سلفة فورية: سجّل السلفة من سلف الموظفين وتُخصم من الخزينة مباشرة
  • الحوافز والخصومات: حافز فوري يُصرف نقداً، أو خصم يُضاف لكشف الراتب
{% endif %} {% if user|has_perm_key:'view_treasuries' or user|has_perm_key:'view_bank_accounts' %}
  • استخدم الخزائن لتسجيل القبض والصرف والتحويل بين الخزائن
  • استخدم الحسابات البنكية لمتابعة الإيداعات والسحوبات والتحويلات
  • راجع الرصيد بعد كل حركة، ثم قارن الحركة بالتقرير المالي
{% endif %} {% if tenant_capabilities|has_capability:"has_insurance_billing" %} {% if user|has_perm_key:'view_insurance_companies' or user|has_perm_key:'view_insurance_claims' %}

  2. اربط بطاقة التأمين بالعميل عند الحاجة
  3. أنشئ المطالبة من فاتورة العميل وتابع حالتها حتى التسوية
  4. لا تلغِ الفاتورة قبل إنهاء المطالبة النشطة
{% endif %} {% endif %} {% if user|has_perm_key:'import_items' or user|has_perm_key:'import_customers' or user|has_perm_key:'import_suppliers' %}

  2. نزّل النموذج، املأ البيانات، ثم ارفعه
  3. راجع الأخطاء قبل اعتماد الاستيراد
  4. تحقق من عدد السجلات بعد الانتهاء
{% endif %} {% if plan_allows_agents and tenant_capabilities|has_capability:"has_agents_module" and user|has_perm_key:'view_agents' %}
