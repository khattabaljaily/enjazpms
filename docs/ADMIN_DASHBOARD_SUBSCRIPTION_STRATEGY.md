# استراتيجية إدارة لوحة مشرف النظام والتسعير

## الهدف العام
تصميم لوحة تحكم مركزية للمشرف العام على النظام لتتمكن من:
- إدارة العملاء (الأنشطة التجارية / Tenants) بشكل كامل
- إدارة الاشتراكات وخطط التسعير للمستويات المختلفة
- متابعة التواصل والدعم الفني
- مراقبة النسخ الاحتياطية والاسترجاع لكل عميل على حدة
- الاطلاع على إحصائيات عامة عن صحة النظام وحالة الاشتراكات

## نماذج النسخ والاشتراكات
### 1. نسخة العميل
يتم تقسيم العميل حسب بنية نموذج الاستخدام:
- `محل واحد بمخزن واحد` (Single Store)
- `محل واحد بمخازن متعددة` (Multi Stock)
- `فروع ومخازن متعددة` (Multi Branch)

### 2. أنواع الاشتراك
لكل نسخة يجب أن يكون هناك ثلاثة أنواع من الاشتراك:
- `شهري` - تجديد تلقائي كل شهر
- `سنوي` - تجديد سنوي مع خصم مقارنة بالشهري
- `مدى الحياة` - دفعة واحدة مع وصول دائم للنسخة (باستثناء خدمات الدعم والتحسين)

## آلية التسعير المقترحة
### A. تسعير القاعدة حسب النسخة
- نسخة `محل واحد بمخزن واحد` هي الأقل تكلفة
- نسخة `محل واحد بمخازن متعددة` أعلى تكلفة بسبب دعم نقاط مخزون إضافية
- نسخة `فروع ومخازن متعددة` الأعلى تكلفة لدعم بنية متعددة الفروع والرقابة المركزية

### B. تأثير عدد المخازن والفروع
- يمكن إضافة مكون تسعير فرعي يعتمد على عدد المخازن أو الفروع
- على سبيل المثال:
  - السعر الأساسي + قيمة إضافية لكل مخزن إضافي
  - أو ترقية تلقائية إلى النسخة `فروع ومخازن متعددة` عند تجاوز الحد المسموح

### C. تسعير الاشتراك حسب النوع
- `شهري` = السعر الأساسي * 1.0
- `سنوي` = السعر الأساسي * 10 إلى 11 (خصم 8%-17%)
- `مدى الحياة` = السعر السنوي * 2.5 إلى 3.0 (دفعة واحدة مع أقل تكلفة طويلة الأجل)

### D. باقات الاشتراك المقترحة
- `تجريبي` - فترة مجانية قصيرة أو سعر منخفض لتجربة المنتج
- `أساسي` - للمشروعات الصغيرة
- `احترافي` - للمشروعات المتوسطة مع دعم تقارير إضافية
- `مؤسسات` - للمشروعات الكبيرة مع فروع متعددة ودعم مخصص

## عناصر لوحة مشرف النظام الأساسية
### 1. إدارة العملاء
- قائمة العملاء/الأنشطة التجارية
- حالة الاشتراك لكل عميل
- تحرير بيانات العميل (معلومات الاتصال، نوع النسخة، عدد الفروع والمخازن)
- عرض نشاط العميل وإحصائياته الأساسية

### 2. إدارة الاشتراكات
- عرض اشتراكات العملاء الحالية
- تحويل العميل بين الخطط أو النسخ
- تجديد الاشتراك يدوياً أو تلقائياً
- تنبيهات انتهاء الاشتراك
- مشاهدة حالة `Trial` و`Paid`

### 3. التواصل والدعم الفني
- تسجيل ملاحظات دعم لكل عميل
- حالة التذاكر أو الطلبات المفتوحة
- ربط الدعم بالبريد الإلكتروني أو نظام داخلي
- إرسال إشعارات للعملاء حول التحديثات أو مشاكل الاشتراك

### 4. النسخ الاحتياطي والاسترجاع
- إدارة النسخ الاحتياطية لكل عميل على حدة
- عرض حالة آخر نسخة احتياطية وتاريخها
- تنفيذ استرجاع بيانات عميل من نسخة محددة
- مراقبة المساحة المستخدمة لكل عميل

### 5. الإحصائيات العامة
- إجمالي عدد العملاء
- عدد العملاء النشطين
- توزيع العملاء حسب النسخة
- توزيع العملاء حسب خطة الاشتراك
- حالة الاشتراكات المنتهية/القريبة من الانتهاء
- نشاط الدعم الفني وخدمات النسخ الاحتياطي

## تخطيط القائمة الجانبية (Sidebar)
### بنية مقترحة للقائمة الجانبية لمشرف النظام
- لوحة التحكم
- إدارة العملاء
- إدارة الاشتراكات
- الدعم الفني
- النسخ الاحتياطية والاسترجاع
- التقارير والإحصائيات
- الإعدادات

### عناصر قابلة للتوسيع لاحقاً
- تقارير مالية ومبيعات على مستوى العميل
- سجل النشاط واللوج لعمليات العملاء
- تصدير واستيراد بيانات العملاء
- مراقبة أداء النظام وخدمات الـ API

## الخطوة الحالية
### تنفيذ مبدئي
- إنشاء صفحة رئيسية جديدة لـ `لوحة مشرف النظام`
- استخدام مخططات وهمية (Dummy Charts) لعرض حجم الاشتراكات وحالة النسخ
- إضافة بطاقات سريعة لأهم مؤشرات الأداء
- إضافة رابط جديد في القائمة الجانبية للسوبر يوزر فقط
- إبقاء باقي الميزات كخطة للتوسعة المستقبلية
